# ข้อมูลโครงการ
ชื่อ: ระบบบริหารจัดการนาข้าวคาร์บอนต่ำด้วยหุ่นยนต์ลอยน้ำและเซนเซอร์ IoT อัจฉริยะ
อังกฤษ: Smart Rice Climate Management System with Floating Robot and IoT Sensor Network
ส่งเข้าประกวด: Science & Technology Idea Contest แนวคิด "วิศวกรรมเชิงหมุนเวียน" (KMUTT)

# ปัญหาและที่มา
- นาข้าวเป็นแหล่งปล่อยก๊าซมีเทน (CH4) สำคัญที่สุดในภาคเกษตรไทย ประมาณ 26.6-36.4 ล้านตัน CO2eq/ปี คิดเป็นมากกว่า 51% ของก๊าซเรือนกระจกภาคเกษตร
- มีเทนมี GWP100 = 27.9 เท่าของ CO2 (IPCC AR6, 2021)
- วิธีตรวจวัดทั่วไปคือ Static Chamber: เก็บตัวอย่าง 3-5 จุด/ไร่, ใช้เวลา 4-8 ชม./ครั้ง, ใช้แรงงานคน, ต้นทุน 5,000-10,000 บาท/ครั้ง, ระบุ Hotspot ไม่แม่น
- เกษตรกรจึงเข้าถึงตลาด Carbon Credit ยาก เพราะขาดระบบ MRV ที่น่าเชื่อถือ
- ปัญหาอื่น: การพึ่งสารกำจัดวัชพืช และขยะอิเล็กทรอนิกส์ (E-Waste) จากอุปกรณ์ IoT

# วัตถุประสงค์
1. หุ่นยนต์ตรวจวัดและทำแผนที่มีเทนในนาภายใน 50 นาที พร้อมกวนน้ำควบคุมวัชพืชโดยไม่ใช้สารเคมี
2. สถานีตรวจวัดพลังงานแสงอาทิตย์ วัดระดับน้ำ ความชื้นดิน อุณหภูมิ เพื่อหนุนการจัดการน้ำแบบ AWD
3. ระบบ AI คาดการณ์ค่า AWD Threshold ล่วงหน้า และแจ้งเตือนผ่าน LINE
4. ฮาร์ดแวร์ตามหลักเศรษฐกิจหมุนเวียน: โครงสร้างพลาสติก HDPE รีไซเคิลได้, โมดูลาร์ถอดประกอบง่าย (Design for Disassembly) มุ่งสู่ Zero E-Waste

# ฮาร์ดแวร์: Methane Rover (หุ่นยนต์ลอยน้ำ)
- ขนาด 65x65 ซม. น้ำหนักประมาณ 1.5 กก.
- สมองกลาง ESP32 DevKit (WROOM-32), Wi-Fi 2.4GHz
- เซนเซอร์มีเทน TGS2611 x2 (ช่วงวัด 500-10,000 ppm)
- GPS u-blox NEO-M8N (±2.5 ม.) บันทึกพิกัดทุก 5 วินาที
- มอเตอร์ DC 12V x2 ขับแปรงยางซ้าย/ขวา (กวนน้ำและขับเคลื่อน) ผ่านไดรเวอร์ L298N
- แบต LiPo 3S 11.1V 3000mAh x2 ใช้งานได้ประมาณ 2-3 ชม.
- บันทึกข้อมูล CSV ลง MicroSD, จอ OLED 0.96" แสดงสถานะ
- เซนเซอร์อัลตราโซนิก JSN-SR04T x4 ตรวจสิ่งกีดขวาง
- ตัวถังโฟม HDPE หนา 30-50 มม. กล่อง IP65 กันน้ำ
- ราคารวม Rover ประมาณ 6,667 บาท

# ฮาร์ดแวร์: Smart AWD Field Node (สถานีตรวจวัดในแปลง)
- ESP32-WROOM-32U (โหมด Deep Sleep ประหยัดพลังงาน)
- วัดระดับน้ำด้วย JSN-SR04T ในท่อ PVC 1.5 นิ้ว, ความชื้นดิน (Capacitive v1.2), อุณหภูมิ/ความชื้นอากาศ/ความดัน (BME280)
- โซลาร์เซลล์ 5W + แบต 18650 x2 + BMS + โมดูลชาร์จ + LM2596
- กล่อง IP65 + ท่อ PVC ใช้เป็นโครงปักลงพื้นที่
- ราคารวม Field Node ประมาณ 1,330 บาท
- ค่าทดสอบ 2,000 บาท รวมทั้งโครงการ 9,997 บาท

# ซอฟต์แวร์และการไหลของข้อมูล
- Sensor Layer -> ESP32 (Edge) -> ส่งผ่าน WiFi (MQTT/HTTP) -> Cloud (Broker + Database)
- Output: Web Dashboard แสดง Heatmap ตามพิกัด GPS + CH4, และ AI Engine วิเคราะห์ anomaly/แจ้งเตือน
- ผู้ใช้ดู Heatmap ผ่านเบราว์เซอร์ และรับแจ้งเตือนผ่าน LINE
- ระบบ Auto-MRV เก็บข้อมูลเพื่อใช้ยื่นขอคาร์บอนเครดิต (TVER)
- ค่าอ้างอิง AWD: ระดับน้ำในท่อลดลงถึง -15 ซม. จึงให้น้ำใหม่

# งานวิจัยและมาตรฐานที่อ้างอิง
- Sriphirom et al. (2019) J. Cleaner Production: AWD ลดมีเทนได้อย่างมีนัยสำคัญและประหยัดน้ำโดยไม่กระทบผลผลิต
- SmartWT (Ngo Manh et al., 2025): เซนเซอร์ IoT เปิดสำหรับวัดระดับน้ำในนา ใช้เป็นแนวออกแบบวงจรและระบบโซลาร์
- IPCC 2006 Guidelines (Scaling Factors) และ IPCC AR6 (GWP100 = 27.9)
- อื่นๆ: IRRI, กรมการข้าว, TGO (T-VER), Green Climate Fund FP214

# ผลที่คาดว่าจะได้รับ
- ลดมีเทน 40-50% หรือประมาณ 0.8-1.2 ตัน CO2eq/ไร่/ปี
- ประหยัดน้ำสูบเข้านา 30% ลดค่าสารเคมีกำจัดวัชพืช 60-80%
- เกษตรกรและวิสาหกิจชุมชนใช้ข้อมูล Auto-MRV ประกอบการขอคาร์บอนเครดิต "ข้าวคาร์บอนต่ำ"
- หน่วยงานรัฐใช้เป็นโมเดลต้นแบบส่งเสริมนาข้าวคาร์บอนต่ำ

# ผลกระทบต่อสังคม
- ลดความเสี่ยงการจัดการน้ำผิดพลาด, ลดช่องว่างเทคโนโลยีของเกษตรกรรายย่อยด้วยแอปภาษาไทย
- ลด E-Waste ด้วยการออกแบบแยกส่วนและซ่อมเองได้
- ฟื้นฟูระบบนิเวศดินและแหล่งน้ำ มุ่งสู่ Carbon Neutrality ปี 2050 และ Net Zero
