# ข้อมูลโครงการ
ชื่อ: ระบบบริหารจัดการนาข้าวคาร์บอนต่ำด้วยหุ่นยนต์ลอยน้ำและเซนเซอร์ IoT อัจฉริยะ
อังกฤษ: Smart Rice Climate Management System with Floating Robot and IoT Sensor Network
ส่งเข้าประกวด: Science & Technology Idea Contest 2026 แนวคิด "วิศวกรรมเชิงหมุนเวียน" (Circular Economy Based Engineering) จัดโดยคณะวิศวกรรมศาสตร์ มจธ. (KMUTT) ทีม PAP รหัส IC21

# ปัญหาและที่มา
- นาข้าวเป็นแหล่งปล่อยก๊าซมีเทน (CH4) สำคัญที่สุดในภาคเกษตรไทย ประมาณ 26.6-36.4 ล้านตัน CO2eq/ปี คิดเป็นมากกว่า 51% ของก๊าซเรือนกระจกภาคเกษตร (ตามข้อเสนอโครงการ)
- ก๊าซมีเทนมีค่า GWP100 = 27.9 เท่าของ CO2 ตาม IPCC AR6 (2021) (หมายเหตุ: AR6 ยังมีค่าอื่นด้วย คือ 29.8 สำหรับมีเทนจากเชื้อเพลิงฟอสซิล และ 27.0 สำหรับมีเทนที่ไม่ใช่ฟอสซิล โครงการนี้ใช้ค่า 27.9 ซึ่งเป็นค่า "มีเทน" ตามที่ AR6 รายงานแยกไว้)
- วิธีตรวจวัดทั่วไปคือ Static Chamber: เก็บตัวอย่าง 3-5 จุด/ไร่, ใช้เวลา 4-8 ชม./ครั้ง, ใช้แรงงานคน, ต้นทุน 5,000-10,000 บาท/ครั้ง, ระบุ Hotspot ได้ไม่แม่นยำ
- เกษตรกรจึงเข้าถึงตลาดคาร์บอนเครดิตยาก เพราะขาดระบบ MRV (Measurement, Reporting, Verification) ที่น่าเชื่อถือ และยังไม่มีเครื่องมือติดตามการจัดการน้ำแบบ AWD ที่แม่นยำ
- ปัญหาอื่น: การพึ่งสารกำจัดวัชพืช (กระทบระบบนิเวศและสุขภาพเกษตรกร) และขยะอิเล็กทรอนิกส์ (E-Waste) จากอุปกรณ์ IoT ที่ออกแบบให้ใช้แล้วทิ้ง ซ่อมยาก ตกค้างในแปลงนา

# สาเหตุที่เกิดก๊าซมีเทนในนาข้าว
- เมื่อน้ำขังในนานาน ออกซิเจนในดินหมดไป เกิดสภาพไร้ออกซิเจน (Anaerobic) ซึ่งเอื้อให้จุลินทรีย์กลุ่ม Methanogens ทำงาน (ในทางวิทยาศาสตร์ Methanogens จัดเป็นอาร์เคีย ไม่ใช่แบคทีเรีย แต่ข้อเสนอโครงการเรียกว่าแบคทีเรีย)
- เศษซากพืชและตอซังเป็นอาหารของจุลินทรีย์ ยิ่งมีมาก ยิ่งสร้างมีเทนมาก
- ก๊าซที่เกิดใต้ดินระบายออกสู่บรรยากาศ โดยทางหลักคือผ่านลำต้นข้าว รองลงมาคือฟองก๊าซและการแพร่ผ่านน้ำ
- เพราะเหตุนี้ การระบายน้ำให้ดินแห้งเป็นช่วงๆ (AWD) จึงช่วยลดมีเทนได้

# วัตถุประสงค์
1. สร้างหุ่นยนต์ตรวจวัดและทำแผนที่มีเทนในนา ภายในเวลาไม่เกิน 50 นาที พร้อมกวนน้ำควบคุมวัชพืชโดยไม่ใช้สารเคมี
2. สร้างสถานีตรวจวัดพลังงานแสงอาทิตย์ วัดระดับน้ำ ความชื้นดิน อุณหภูมิ เพื่อสนับสนุนการจัดการน้ำแบบ AWD
3. พัฒนาระบบสนับสนุนการตัดสินใจด้วย AI คาดการณ์ค่า AWD Threshold ล่วงหน้า และแจ้งเตือนผ่าน LINE
4. ออกแบบฮาร์ดแวร์ตามหลักวิศวกรรมเชิงหมุนเวียน: โครงสร้างพลาสติก HDPE รีไซเคิลได้ สถาปัตยกรรมโมดูลาร์ถอดประกอบง่าย (Design for Disassembly) มุ่งสู่เป้าหมาย Zero E-Waste

# ฮาร์ดแวร์: Methane Rover (หุ่นยนต์ลอยน้ำ)
- ขนาด 65x65 ซม. น้ำหนักประมาณ 1.5 กก.
- สมองกลาง ESP32 DevKit (WROOM-32) พร้อม Wi-Fi 2.4GHz
- เซนเซอร์มีเทน TGS2611 x2 (ช่วงวัด 500-10,000 ppm)
- GPS u-blox NEO-M8N (ความแม่นยำ ±2.5 ม.) บันทึกพิกัดทุก 5 วินาที (โปสเตอร์ระบุว่าบันทึกได้มากกว่า 400 จุดต่อไร่)
- มอเตอร์ DC 12V x2 ขับแปรงยางซ้าย/ขวา (ทำหน้าที่ทั้งขับเคลื่อนและกวนน้ำ) ผ่านไดรเวอร์ L298N
- แบตเตอรี่ LiPo 3S 11.1V 3000mAh x2 ใช้งานได้ประมาณ 2-3 ชม.
- บันทึกข้อมูล CSV ลง MicroSD, จอ OLED 0.96 นิ้วแสดงสถานะ
- เซนเซอร์อัลตราโซนิกกันน้ำ JSN-SR04T x4 ตรวจจับสิ่งกีดขวาง
- ตัวถังโฟม HDPE หนา 30-50 มม. กล่อง IP65 กันน้ำ
- ราคารวม Rover 6,667 บาท (รายการสายไฟและ Connector เป็นช่วงราคา 500-800 บาท ผลรวม 6,667 บาท คำนวณจากค่าสูงสุด 800 บาท)

# ฮาร์ดแวร์: Smart AWD Field Node (สถานีตรวจวัดในแปลง)
- ESP32-WROOM-32U ใช้โหมด Deep Sleep ประหยัดพลังงาน
- วัดระดับน้ำด้วย JSN-SR04T ในท่อ PVC 1.5 นิ้ว, ความชื้นดิน (Capacitive v1.2), อุณหภูมิ/ความชื้นอากาศ/ความดัน (BME280)
- โซลาร์เซลล์ 5W + แบตเตอรี่ 18650 x2 + BMS + โมดูลชาร์จ + LM2596
- กล่อง IP65 + ท่อ PVC ใช้เป็นโครงปักลงพื้นที่
- ราคารวม Field Node 1,330 บาทต่อ 1 สถานี (ต้องมีทุกแปลง ส่วน Rover ใช้ร่วมกันได้หลายแปลง)

# งบประมาณ
- Rover 6,667 + Field Node 1,330 + ค่าทดสอบ 2,000 = 9,997 บาท (ต้นแบบ 1 ชุด)
- ตัวเลขเป็นการประมาณราคาตลาดโดยคณะผู้ประดิษฐ์ (ปี 2569)

# ซอฟต์แวร์และการไหลของข้อมูล
- Sensor -> ESP32 (Edge) -> ส่งผ่าน WiFi (MQTT/HTTP) -> Cloud (Broker + ฐานข้อมูล: เก็บ GPS, CH4, ระดับน้ำ, เวลา)
- Output: เว็บแดชบอร์ดภาษาไทยแสดงฮีตแมปตามพิกัด GPS + ค่ามีเทน และ AI Engine
- ฮีตแมป: เขียว = ค่าต่ำ, เหลือง = เฝ้าระวัง, แดง = Hotspot (จุดที่ปล่อยมีเทนสูงกว่าจุดอื่นอย่างชัดเจน)
- ผู้ใช้ดูฮีตแมปผ่านเบราว์เซอร์ (คอมพิวเตอร์ iPad มือถือ) และรับแจ้งเตือนผ่าน LINE
- เว็บ Dashboard ตัวอย่าง: http://ac54241.assumptiondev.com/methanetast/index.html (ใช้ข้อมูลจำลอง)

# AI-assisted Decision Support
หน้าที่ที่ออกแบบไว้:
1. คาดการณ์ค่า AWD Threshold ล่วงหน้า จากระดับน้ำ ความชื้นดิน อุณหภูมิ ว่าอีกกี่วันระดับน้ำในท่อจะลดถึง -15 ซม. (เกณฑ์ AWD ที่ใช้อ้างอิงจากงานวิจัย) เพื่อแจ้งเกษตรกรว่าเมื่อไรต้องปล่อยน้ำเข้านา
2. เตือนความผิดปกติ เช่น ค่ามีเทนสูงผิดธรรมชาติ หรืออุปกรณ์ขาดการเชื่อมต่อ
3. แจ้งเตือนเกษตรกรผ่าน LINE ไม่ต้องติดตั้งแอปใหม่
4. คำนวณปริมาณ CO2eq ที่ลดได้ โดยใช้จำนวนวันแห้งจริงที่สถานีบันทึก ตามสูตร IPCC 2006 (Scaling Factors) และ GWP100 จาก AR6 เพื่อเป็นข้อมูล MRV ที่ตรวจสอบย้อนหลังได้
สถานะ: ข้อเสนอโครงการไม่ได้ระบุชื่อโมเดล AI และยังไม่มีผลประเมินความแม่นยำกับข้อมูลจริง ถ้าถูกถาม ให้ตอบว่าเป็นต้นแบบ
ขั้นต่อยอด (แผนอนาคต ยังไม่ได้ทำ): เชื่อม AI กับระบบเปิด-ปิดน้ำอัตโนมัติ เป็น Closed-Loop Smart AWD

# การพิสูจน์การลดมีเทน (แผนที่วางไว้)
การวัดค่าก๊าซได้ ไม่เท่ากับการลดการปล่อยได้ ต้องเปรียบเทียบ แผนพิสูจน์ 3 ขั้น
1. เทียบแปลงทดลองแบบ AWD กับแปลงควบคุมที่ขังน้ำตลอด ภายใต้เงื่อนไขเดียวกัน
2. ใช้จำนวนวันแห้งจริงจาก Field Node คำนวณตามสูตร IPCC 2006 เพื่อประเมิน CO2eq ที่ลดได้
3. สอบเทียบเซนเซอร์มีเทนกับวิธี Static Chamber ในแปลงเล็ก
ข้อจำกัดที่ต้องบอกตรงๆ: เซนเซอร์ TGS2611 เหมาะกับการเปรียบเทียบเชิงสัมพัทธ์และหา Hotspot มากกว่าการวัดค่าการปล่อยแบบสัมบูรณ์ และ AWD อาจเพิ่มก๊าซไนตรัสออกไซด์ (N2O) เล็กน้อย ซึ่งควรติดตามในการทดลองจริง

# คาร์บอนเครดิต
- ระบบช่วยจัดเตรียมข้อมูลสำหรับ MRV ให้เป็นระบบและตรวจสอบย้อนหลังได้ (Auto-MRV)
- การได้คาร์บอนเครดิตจริงต้องผ่านการตรวจสอบและรับรองตามเกณฑ์ของ T-VER จากองค์การบริหารจัดการก๊าซเรือนกระจก (อบก. / TGO) ระบบนี้ไม่ได้รับรองคาร์บอนเครดิตเอง
- รายได้จากคาร์บอนเครดิตเป็นรายได้เสริม ผลตอบแทนที่ชัดเจนกว่าคือการประหยัดน้ำและลดค่าสารเคมี

# เป้าหมายและสมมติฐาน (ยังไม่ใช่ผลที่วัดได้เอง)
- ลดการปล่อยมีเทน 40-50% หรือประมาณ 0.8-1.2 ตัน CO2eq/ไร่/ปี (ตามข้อเสนอโครงการ)
- ประหยัดน้ำที่สูบเข้านา 30%
- ลดค่าสารเคมีกำจัดวัชพืช 60-80% (ด้วยแปรงยางกวนน้ำ)
- ผลผลิตข้าวคงเท่าเดิม
- ประหยัดเวลาตรวจวัดเมื่อเทียบกับ Static Chamber ประมาณ 79-90% (คำนวณจาก 50 นาที เทียบ 4-8 ชั่วโมง)
- ที่มา: งานวิจัยในประเทศไทย เช่น Sriphirom et al. (2019)

# แนวคิดวิศวกรรมเชิงหมุนเวียน: สูตร 5 คืน
1. คืนอากาศสะอาด: ตรวจจับและลดการปล่อยมีเทนด้วยหุ่นยนต์และการจัดการน้ำแบบ AWD
2. คืนน้ำสู่ธรรมชาติ: ระบบเซนเซอร์ช่วยประหยัดการสูบน้ำ ตั้งเป้า 30%
3. คืนความปลอดภัยสู่ผิวดิน: แปรงยางหมุนใต้ผิวน้ำขัดขวางวัชพืชด้วยกลไก ไม่มีสารเคมีตกค้างในดิน
4. คืนพลังงานสะอาด: โซลาร์เซลล์ + แบตเตอรี่ชาร์จซ้ำได้ + โหมดประหยัดพลังงาน (Deep Sleep)
5. คืนมูลค่าฮาร์ดแวร์ (Zero E-Waste): ตัวถัง HDPE รีไซเคิลได้ ออกแบบเป็นโมดูลถอดซ่อมได้รายชิ้น (Design for Disassembly) ใช้ขั้วต่อแทนการบัดกรีตายตัว เกษตรกรเปลี่ยนเฉพาะชิ้นที่เสียได้เอง

# ขยะอิเล็กทรอนิกส์ (E-Waste)
- ปัญหา: อุปกรณ์ IoT ทางการเกษตรจำนวนมากใช้แล้วทิ้ง ซ่อมยาก ตกค้างในแปลงนา
- วิธีแก้: Design for Disassembly, ตัวถัง HDPE รีไซเคิลได้, โมดูลถอดเปลี่ยนได้
- Zero E-Waste เป็นเป้าหมายที่มุ่งไป ไม่ได้แปลว่าไม่มีขยะเลย เพราะแบตเตอรี่และชิปยังเป็นขยะอิเล็กทรอนิกส์ได้
- แผนต่อยอด (ยังไม่ได้ทำ): ศูนย์รับคืนชิ้นส่วน (Trade-in and Refurbish Hub) รับอุปกรณ์เก่าแลกของใหม่ ชิ้นส่วนที่ใช้ได้นำไปปรับปรุงใช้ซ้ำ ที่หมดอายุส่งรีไซเคิล

# แผนต่อยอด (ทั้งหมดยังเป็นแผนอนาคต)
1. AI เชื่อมระบบเปิด-ปิดน้ำอัตโนมัติ (Closed-Loop Smart AWD)
2. แดชบอร์ดออกรายงาน MRV แยกรายแปลง
3. ศูนย์รับคืนและปรับปรุงชิ้นส่วน (Trade-in and Refurbish Hub)
4. ฐานข้อมูลเพื่อการวางแผนเกษตรยั่งยืน (Big Data for Policy and Planning)

# งานวิจัยและมาตรฐานที่อ้างอิง
- Sriphirom, Chidthaisong, Towprayoon (2019) Journal of Cleaner Production: AWD ลดมีเทนได้อย่างมีนัยสำคัญและประหยัดน้ำ โดยไม่กระทบผลผลิต
- SmartWT (Ngo Manh et al., 2025) Computers and Electronics in Agriculture: เซนเซอร์ IoT เปิดสำหรับวัดระดับน้ำในนา ใช้เป็นแนวทางออกแบบวงจรและระบบโซลาร์
- IPCC 2006 Guidelines Vol.4 Ch.5 (Scaling Factors สำหรับสูตรคำนวณ) และ IPCC AR6 (GWP100)
- อื่นๆ: IRRI, กรมการข้าว, TGO (T-VER), Green Climate Fund FP214

# ผลกระทบต่อสังคม
- ลดความเสี่ยงการจัดการน้ำผิดพลาด และลดช่องว่างเทคโนโลยีของเกษตรกรรายย่อยด้วยแอปภาษาไทย
- ลด E-Waste ด้วยการออกแบบแยกส่วนและซ่อมเองได้
- ฟื้นฟูระบบนิเวศดินและแหล่งน้ำ สนับสนุนเป้าหมาย Carbon Neutrality ปี 2050 และ Net Zero
